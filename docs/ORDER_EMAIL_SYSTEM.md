# 주문 이메일 시스템 가이드

merchandisegpt의 주문 처리 및 이메일 전송 시스템에 대한 상세 가이드입니다.

## 📧 이메일 자동 발송 시스템

주문이 접수되면 자동으로 **2개의 이메일**이 발송됩니다:

### 1. 거래처(제조사)용 이메일
- **받는 사람**: `ORDER_EMAIL_TO` 환경 변수에 설정된 이메일
- **제목**: 🎽 새 주문: [주문번호] - [주문자명]
- **첨부 파일**:
  - **주문서 PDF**: 주문 정보, 디자인 이미지, 목업 이미지 포함
  - **인쇄용 PNG**: 텍스트가 고정된 최종 디자인 이미지 (업스케일링 완료)

### 2. 고객용 이메일
- **받는 사람**: 주문 시 입력한 고객 이메일
- **제목**: ✅ 주문 접수 완료: [주문번호]
- **첨부 파일**:
  - **주문서 PDF**: 주문 내역 확인용

## 📄 주문서 PDF 내용

### 포함되는 정보
1. **주문 기본 정보**
   - 주문번호
   - 주문일시
   - 주문 채널

2. **고객 정보**
   - 이름
   - 전화번호
   - 이메일

3. **배송 정보**
   - 수령인
   - 전화번호
   - 배송 주소 (주소1, 주소2, 도시, 주/도, 우편번호, 국가)
   - 배송 메모

4. **주문 상품**
   - 제품명
   - 모델명
   - 색상, 사이즈, 수량
   - 인쇄 방법 및 위치
   - 인쇄 크기
   - 텍스트 레이어 정보

5. **이미지 (실제 이미지 임베드)**
   - **디자인 이미지**: 텍스트가 포함된 최종 디자인 (최대 250x250px)
   - **목업 이미지**: 제품에 적용된 미리보기 (각 최대 200x200px)

6. **가격 정보**
   - 단가
   - 수량
   - 배송비
   - 총액

## 🖼️ 인쇄용 PNG 생성 프로세스

### 1. 텍스트 합성
클라이언트(앱)에서 이미지와 텍스트를 합성하여 최종 디자인을 생성합니다:
- 배경 이미지 (디자인)
- 텍스트 레이어 (위치, 폰트, 크기, 색상 고정)
- 두 요소를 합성한 PNG

### 2. 업스케일링
서버의 Print Pipeline이 자동으로 실행됩니다:
- Clipdrop API를 사용한 AI 업스케일링
- 기본 타겟 크기: **2480 x 3508 픽셀** (A4, 300 DPI)
- 고해상도 인쇄용 파일 생성

### 3. 품질 검사
- 자동 QC (Quality Check) 실행
- 이미지 품질 확인
- 경고만 있으면 통과, 에러만 실패 처리

### 4. 파일 저장 및 첨부
- `server_data/orders/[주문번호]/` 디렉토리에 저장
- 거래처 이메일에 자동 첨부

## ⚙️ 환경 변수 설정

### 필수 설정
```bash
# SMTP 설정 (이메일 발송)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
SMTP_FROM=merchandisegpt@example.com

# 주문 접수 이메일 (거래처)
ORDER_EMAIL_TO=manufacturer@example.com

# Clipdrop API (업스케일링)
CLIPDROP_API_KEY=your-clipdrop-api-key
```

### Gmail 사용 시 설정
1. Gmail 계정 설정 → 보안
2. 2단계 인증 활성화
3. 앱 비밀번호 생성
4. `SMTP_PASS`에 앱 비밀번호 입력

## 🔄 주문 처리 플로우

```
주문 접수
    ↓
클라이언트: 이미지 + 텍스트 합성 PNG 생성
    ↓
서버: /v1/orders/submit 호출
    ↓
Pipeline 실행 (기본 활성화)
    ├─ 디자인 이미지 다운로드
    ├─ Clipdrop API로 업스케일링 (2480x3508px)
    ├─ QC (품질 검사)
    └─ 인쇄용 PNG 저장
    ↓
PDF 생성
    ├─ 주문 정보 작성
    ├─ 디자인 이미지 임베드
    ├─ 목업 이미지 임베드
    └─ PDF 파일 생성
    ↓
S3 저장 (옵션)
    └─ order.storePdf: true 시 S3에 업로드
    ↓
이메일 발송
    ├─ 거래처: PDF + 인쇄용 PNG 첨부
    └─ 고객: PDF 첨부
    ↓
Kakao 알림 (옵션)
    └─ 주문 접수 알림
    ↓
완료
```

## 🎨 커스터마이징

### Pipeline 비활성화
특정 주문에서 업스케일링을 건너뛰려면:
```json
{
  "pipeline": {
    "enabled": false
  }
}
```

### 커스텀 업스케일링 크기
```json
{
  "pipeline": {
    "enabled": true,
    "targetWidthPx": 3000,
    "targetHeightPx": 4000
  }
}
```

### PDF S3 저장
```json
{
  "storePdf": true
}
```

## 📊 로그 및 모니터링

### 주요 로그 이벤트
- `order_submit_request`: 주문 접수 요청
- `pipeline_completed`: 업스케일링 완료
- `pipeline_failed`: 업스케일링 실패
- `pdf_image_embed_failed`: PDF 이미지 임베드 실패
- `png_attachment_failed`: PNG 첨부 실패

## 🐛 트러블슈팅

### 이메일이 발송되지 않음
1. SMTP 환경 변수 확인
2. Gmail의 경우 앱 비밀번호 확인
3. 방화벽에서 SMTP 포트(465) 허용 확인

### 업스케일링 실패
1. `CLIPDROP_API_KEY` 확인
2. Clipdrop API 크레딧 잔액 확인
3. 이미지 파일 크기 제한 확인 (너무 크거나 작으면 실패)

### PDF에 이미지가 표시되지 않음
1. 이미지 URL이 공개적으로 접근 가능한지 확인
2. S3 버킷의 CORS 설정 확인
3. 로그에서 `pdf_image_embed_failed` 이벤트 확인

### PNG 파일이 첨부되지 않음
1. Pipeline이 활성화되어 있는지 확인
2. `pipelineResult.output_path` 경로에 파일이 생성되었는지 확인
3. 로그에서 `pipeline_failed` 이벤트 확인
