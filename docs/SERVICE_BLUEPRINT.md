# 굿즈메이커 서비스 블루프린트 & UI/UX 설계문서

> **앱 이름**: 굿즈메이커 (MerchandiseGPT)
> **플랫폼**: 토스 미니앱 (Apps in Toss)
> **최종 업데이트**: 2026-03-22

---

## 1. 서비스 개요

AI 기반 커스텀 의류(티셔츠/후드/맨투맨) 디자인 → 주문 → 결제까지 원스톱 제공.
토스 앱 내에서 실행되므로 **별도 로그인 불필요** (토스 세션 자동 연동).

### 핵심 가치
| 가치 | 설명 |
|------|------|
| **즉시성** | AI 프롬프트 한 줄로 디자인 완성 |
| **접근성** | 토스 앱 안에서 디자인부터 결제까지 |
| **품질** | Vertex AI 업스케일 + 고해상도 인쇄 파이프라인 |

### 2.2 단계별 터치포인트

| 단계 | 사용자 행동 | 시스템 반응 | 실패 시나리오 |
|------|-----------|-----------|-------------|
| **진입** | 토스앱에서 미니앱 실행 | 토스 세션 자동 연동, 홈 렌더링 | 세션 만료 → 토스 재로그인 |
| **탐색** | 캐러셀 스와이프, FAQ 확인 | 상품별 목업 프리뷰 표시 | 이미지 로드 실패 → fallback |
| **생성** | AI 프롬프트 입력 / 사진 업로드 | Gemini 생성 or GCS 업로드 | 생성 실패 → 재시도 버튼 |
| **편집** | 위치/크기/회전 조절, 텍스트 추가 | 실시간 캔버스 반영 | — |
| **확인** | 색상/사이즈 선택, 가격 확인 | 가격 자동 계산 (할증 포함) | — |
| **결제** | 배송지 입력 → 토스페이 | 주문서 PDF 생성, 이메일 발송 | 결제 실패 → 에러 토스트 |

## 3. UI Hierarchy (화면 계층 구조)

### 3.1 전체 네비게이션 트리

```
/ (홈)
├── /generate (AI 디자인 생성)
│   └── → /editor
├── /upload (사진 업로드)
│   └── → /editor
├── /editor (디자인 편집)
│   └── → /preview
├── /preview (미리보기)
│   ├── → /order (결제)
│   └── → /designs (저장)
├── /products (상품 카탈로그)
│   └── → /editor
├── /designs (저장된 디자인)
│   └── → /editor (재편집)
├── /order (주문/결제)
├── /faq (자주 묻는 질문)
├── /inquiry (문의하기)
├── /privacy (개인정보처리방침)
├── /terms (이용약관)
└── /open (딥링크 핸들러) → /
```

### 3.2 페이지별 뷰포트 & 스크롤 분석

| 페이지 | 스크롤 | 한 화면 완결? | 고정 헤더 | 고정 하단 | 특수 동작 |
|--------|--------|:----------:|:-------:|:-------:|----------|

| `/generate` AI 생성 | Screen(ScrollView) | ❌ | ✅ PageHeader | ✅ 하단 액션버튼 | 풀스크린 로더, 옵션 모달 |

| `/order` 주문 | Screen(ScrollView) + 모달 | ❌ | ✅ 커스텀 헤더 | ✅ 결제 버튼 | 주소검색 모달, 폼 확장 |

| `/inquiry` 문의 | Screen(ScrollView) | ❌ | ✅ 커스텀 헤더 | ✅ "제출" 버튼 | textarea(120px)+입력필드 |

| `/terms` 이용약관 | Screen + 중첩 ScrollView | ❌ | ✅ 커스텀 헤더 | — | 긴 법률 문서 |
| `/open` 딥링크 | 없음 (스플래시) | ✅ | — | — | 자동 리다이렉트 → `/` |

> **범례**: ✅ 있음 · ❌ 한 화면 안됨 · ⚠️ 조건부 · — 없음

## 4. CTA 구성 & 전환 전략

### 4.1 Primary CTA (주요 행동 유도)

| 위치 | CTA 텍스트 | 타입 | 목적 |
|------|-----------|------|------|
| 홈 Hero | **지금 만들어보기** | Primary Button | 핵심 전환: 홈 → 에디터 진입 |
| 에디터 Header | **미리보기** | Text Button | 편집 완료 → 확인 단계 |
| 미리보기 하단 | **결제하기** | Primary Button | 결제 전환 |
| 주문 하단 | **토스페이로 결제하기** | Primary Button | 최종 결제 |

### 4.2 Secondary CTA (보조 행동)

| 위치 | CTA 텍스트 | 타입 | 목적 |
|------|-----------|------|------|
| 홈 캐러셀 카드 | 카드 탭 | Pressable Card | 상품별 에디터 진입 |
| 홈 하단 | 세부 정보 보기 → | Text Link | 상품 상세 탐색 |
| 에디터 캔버스 | ＋ | Circle Button | 사진 추가 |
| 에디터 탭 | 배경 제거 | Secondary Button | 디자인 정교화 |
| 미리보기 하단 | 디자인 저장하기 | Secondary Button | 이탈 방지 (저장) |
| 주문 | 주소 검색 | Secondary Button | 배송지 입력 |

### 4.3 전환 퍼널

```
홈 방문 (100%)
  ↓ "지금 만들어보기" or 캐러셀 탭

  ↓ 생성 완료

  ↓ "미리보기"
미리보기 (예상 35%)
  ├─ "저장하기" (이탈 회수)
  ↓ "결제하기"
주문 페이지 (예상 20%)
  ↓ "토스페이로 결제하기"
결제 완료 (예상 12%)
```

```
총 금액 = (기본가 + 사이즈 할증 + 뒷면 인쇄비 + 대형 인쇄비) × 수량 + 배송비

뒷면 인쇄비: ₩6,000/장
대형 인쇄비 (A3+): ₩2,000/장
배송비: ₩3,000 (₩60,000 이상 무료)
```

## 9. 인쇄 파이프라인 (Production Flow)

```
사용자 디자인 이미지
  ↓
① Vertex AI Imagen 4.0 업스케일 (800×800 → 3200×3200)
  ↓
② rembg 배경 제거 (고해상도에서 정밀 처리)
  ↓
③ QC 검증 (has_alpha, 투명도 비율, 해상도 확인)
  ↓
④ 인쇄 영역 배치 (cm → px 변환)
  ↓
⑤ Print-ready PNG 출력
  ↓
⑥ PDFKit 주문서 생성 (NotoSansKR 한글 폰트)
  ↓
⑦ Gmail SMTP 주문서 + 인쇄파일 이메일 발송
```
