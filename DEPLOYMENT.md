# Deployment Guide - T-Shirt Maker App

## Overview
This app allows users to create custom t-shirt designs with AI image generation or image upload, preview mockups, and submit orders via email with PDF order forms.

## Features Implemented
- ✅ Product catalog (티셔츠, 맨투맨, 후드)
- ✅ AI image generation with style transfer
- ✅ Image upload with background removal
- ✅ Text layer editor with color picker (블랙/화이트)
- ✅ Front/back mockup toggle (at least one must be active)
- ✅ PDF order form generation with images
- ✅ Email sending to admin
- ✅ FAQ system
- ✅ 1:1 inquiry system with PostgreSQL
- ✅ Kakao Maps address search API (backend ready)

## Environment Variables Setup

### Required Variables for Railway

Add these environment variables in your Railway project dashboard:

```bash
# Database (Auto-generated by Railway PostgreSQL addon)
DATABASE_URL=postgresql://user:pass@host:port/dbname

# OpenAI API (Required)
OPENAI_API_KEY=sk-...
OPENAI_IMAGE_MODEL=dall-e-3
OPENAI_IMAGE_QUALITY=standard

# Email Configuration (Required for order submission)
ORDER_EMAIL_TO=admin@yourcompany.com
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password

# Kakao Maps API (Optional - for address search)
KAKAO_REST_API_KEY=your_kakao_rest_api_key

# Clipdrop API (Optional - for background removal)
CLIPDROP_API_KEY=your_clipdrop_api_key

# S3 Storage (Optional - for storing PDFs/images)
S3_PUBLIC_BASE_URL=https://storage.railway.app
S3_BUCKET=your-bucket-name
AWS_ACCESS_KEY_ID=your_access_key
AWS_SECRET_ACCESS_KEY=your_secret_key
AWS_REGION=us-east-1

# Toss Callback Auth (Optional but recommended for production)
TOSS_CALLBACK_USERNAME=your_username
TOSS_CALLBACK_PASSWORD=your_secure_password
```

## Toss Apps-in-Toss Configuration

### 연결 끊기 콜백 설정

토스 앱인토스 개발자 콘솔에서 다음과 같이 설정하세요:

#### 1. 콜백 URL
```
https://your-app.railway.app/v1/toss/disconnect
```

#### 2. HTTP 메서드
- **POST** (권장) 또는 GET
- 서버에서 둘 다 지원합니다

#### 3. Basic Auth 헤더 (선택사항, 권장)

**Railway 환경 변수 추가:**
```bash
TOSS_CALLBACK_USERNAME=your_username
TOSS_CALLBACK_PASSWORD=your_secure_password
```

**토스 개발자 콘솔 설정:**
- Basic Auth 헤더 활성화
- Username: `your_username`
- Password: `your_secure_password`

**보안 참고사항:**
- Basic Auth를 설정하지 않으면 서버는 인증 없이 요청을 처리합니다 (개발 단계용)
- 프로덕션에서는 반드시 Basic Auth를 설정하세요
- 강력한 비밀번호를 사용하세요 (최소 16자, 영문+숫자+특수문자)

**엔드포인트 동작:**
- 사용자가 앱을 탈퇴하거나 연결을 끊을 때 호출됩니다
- Basic Auth로 요청을 검증합니다
- 현재는 이벤트 로깅만 수행합니다

## Step-by-Step Deployment

### 1. Set up PostgreSQL Database

1. Go to your Railway project dashboard
2. Click "New" → "Database" → "Add PostgreSQL"
3. Railway will automatically create `DATABASE_URL` environment variable
4. The database will auto-initialize tables on first server startup

**Tables created automatically:**
- `inquiries` - User inquiries
- `inquiry_replies` - Admin responses to inquiries

### 2. Configure Email Service (Gmail Example)

1. **Enable 2-Factor Authentication** on your Gmail account
2. **Generate App Password:**
   - Go to Google Account → Security → 2-Step Verification
   - Scroll down to "App passwords"
   - Select "Mail" and "Other (Custom name)"
   - Copy the generated 16-character password

3. **Set Environment Variables:**
   ```bash
   ORDER_EMAIL_TO=your-admin-email@gmail.com
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=465
   SMTP_SECURE=true
   SMTP_USER=your-email@gmail.com
   SMTP_PASS=xxxx xxxx xxxx xxxx  # App password from step 2
   ```

### 3. Get Kakao Maps API Key (Optional)

1. **Create Kakao Developer Account:**
   - Visit https://developers.kakao.com
   - Sign up or log in

2. **Create Application:**
   - Go to "내 애플리케이션" (My Applications)
   - Click "애플리케이션 추가하기" (Add Application)
   - Fill in app name and company info

3. **Get REST API Key:**
   - In your app dashboard, go to "앱 키" (App Keys)
   - Copy "REST API 키"

4. **Enable Kakao Maps (Required since 2024.12.1):**
   - Go to "제품 설정" (Product Settings) → "Kakao 지도" (Kakao Maps)
   - Enable the service

5. **Add Platform:**
   - Go to "플랫폼" (Platform)
   - Add "Web" platform
   - For local development: `http://localhost:3000`
   - For production: Your Railway app URL

6. **Set Environment Variable:**
   ```bash
   KAKAO_REST_API_KEY=your_rest_api_key_here
   ```

### 4. Get OpenAI API Key (Required)

1. Visit https://platform.openai.com/api-keys
2. Create a new API key
3. Copy and save it securely
4. Set environment variables:
   ```bash
   OPENAI_API_KEY=sk-...
   OPENAI_IMAGE_MODEL=dall-e-3
   OPENAI_IMAGE_QUALITY=standard
   ```

### 5. Get Clipdrop API Key (Optional - for background removal)

1. Visit https://clipdrop.co/apis
2. Sign up and get API key
3. Set environment variable:
   ```bash
   CLIPDROP_API_KEY=your_clipdrop_api_key
   ```

### 6. Deploy to Railway

1. **Connect Repository:**
   ```bash
   git add .
   git commit -m "feat: complete t-shirt maker app with all features"
   git push origin main
   ```

2. **Railway will automatically:**
   - Detect Node.js project
   - Run `npm install`
   - Run `npm run build`
   - Start server with `npm start`

3. **Verify Deployment:**
   - Check Railway logs for "Server running on port..."
   - Visit your app URL
   - Test health endpoint: `https://your-app.railway.app/health`

## Troubleshooting

### Email not sending
1. Check `ORDER_EMAIL_TO` is set correctly
2. Verify SMTP credentials are correct
3. For Gmail: Ensure app password is used (not account password)
4. Check Railway logs for SMTP errors

### Database connection failed
1. Verify `DATABASE_URL` is set by Railway PostgreSQL addon
2. Check Railway PostgreSQL is running
3. Review database initialization logs

### Kakao address search not working
1. Verify `KAKAO_REST_API_KEY` is set
2. Check Kakao Maps is enabled in app settings
3. Verify platform URL is added in Kakao developer console

### Images not loading
1. Check `server-public/mockups/` directory contains all images
2. Verify server static file serving: `app.use('/mockups', express.static(...))`
3. Test direct URL: `https://your-app.railway.app/mockups/tshirt_white_front.jpg`

### AI image generation fails
1. Verify `OPENAI_API_KEY` is valid
2. Check OpenAI account has credits
3. Review Railway logs for OpenAI error messages
